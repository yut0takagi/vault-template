# 思考/

**持論・仮説・着想を格納するディレクトリ。ナレッジ（事実）とは分離する。**

## ナレッジ との違い

| | ナレッジ/ | 思考/ |
|---|---|---|
| 中身 | 検証済みの事実・客観情報 | 自分の意見・仮説・気づき・問い |
| 主語 | 一般 | "私は〜と考える" |
| 賞味期限 | 長期保存 | 検証されたらナレッジに昇格、否定されたらアーカイブ |
| 引用元 | 出典明記 | 出典不要（自分の頭から出たもの） |

## ファイル構造

自由。日付付きでもテーマ別でも、自分が見つけやすい形でよい。

```
思考/
├── 2026-05-27_AI時代のキャリア仮説.md
├── 提案資料の作り方持論.md
└── 仮説/
    └── リテールメディアの未来.md
```

## frontmatter 推奨

```yaml
---
status: 仮説 | 検証中 | 確定 | 棄却
created: 2026-05-27
tags: [思考, AI戦略]
---
```

検証されたら本文を整え `ナレッジ/` へ移動。棄却されたら `アーカイブ/` へ。
