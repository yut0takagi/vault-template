# ナレッジフォルダ作成の厳格ルール

## 原則: 新規フォルダは作らない

ナレッジを保存する際は、**既存のフォルダ構造に従う**。新しいフォルダを作成してはならない。

保存前に `ls ナレッジ/` で最新構造を確認すること。ナレッジ/直下のサブフォルダ構成は各vault運用者が決める。

## 新規フォルダが必要だと思った場合

以下のチェックを全て通過した場合のみ作成を提案（自動作成は禁止）:

1. **既存フォルダを全て確認** — `ls ナレッジ/*/` でサブフォルダも含め確認
2. **類似名がないか検証** — 「技術」と「ツール・技術」のような意味的重複がないか
3. **既存フォルダのREADMEを読む** — 対象フォルダのスコープを理解する
4. **ユーザーに確認する** — 「既存の〇〇フォルダに入れますか？それとも新規フォルダが必要ですか？」と聞く

## 禁止パターン

- 同じテーマの別名フォルダを作る（例: 「技術」があるのに「ツールと技術」を作る）
- スキルが自動的にフォルダを生成する際にも、このルールを適用する
- サブフォルダの乱立（1〜2ファイルしか入らないサブフォルダは作らない）
