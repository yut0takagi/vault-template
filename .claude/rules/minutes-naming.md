# 議事録の命名規則とフォルダ構造

## フォルダ構造

```
議事録/{YYYY}/{MM}/
```

- 年 → 月の2階層。日のサブフォルダは作らない
- フォルダがなければ `mkdir -p` で作成

## ファイル名

```
YYYY-MM-DD_タイトル.md
```

### 日付部分

- ISO 8601 形式: `YYYY-MM-DD`（ゼロ埋め）
- 音声ファイル由来: Recording ファイル名の先頭8桁から変換
- 文字起こし由来: ファイル名の日付部分をそのまま使用
- Meet Transcript: カレンダー予定の日付を使用

### タイトル部分

- **区切り文字:** 日付とタイトルの間はアンダースコア `_` 1つ
- **日本語で簡潔に:** 何の会議か一目でわかる表現（30文字以内目安）
- **補足は丸括弧:** 主題が同じ会議の区別には `（補足）` を使う
  - 例: `2026-03-09_提案レビュー（第1回）.md`
- **中点 `・` で並列:** 複数トピックは中点でつなぐ
  - 例: `2026-03-06_プロジェクト進捗確認・業務フロー整備.md`

### 禁止パターン

- `A_`, `B_` 等の順序プレフィクス → 丸括弧で表現する
- ハイフン区切りの英語タイトル → 日本語タイトルに統一
- `議事録：` 等のメタ接頭辞 → ファイル内のヘッダーで表現する
- 同日に同名の会議がある場合は `_meet` サフィックスではなく `（補足）` で区別

## 同日複数会議の例

```
2026-03-18_企画打ち合わせ.md
2026-03-18_提案レビュー（第6回）.md
```
