# 完了宣言プロトコル

「完了しました」等の完了表現は、以下を通過した後にのみ使用可。

**チェックリスト（全タスク共通）:**
1. **元の依頼を再読** — 要求を全て満たしたか確認
2. **TodoWrite確認** — 未完了タスクがないか確認
3. **成果物の実在確認** — ファイルが存在し内容が期待通りか
4. **タイプ別検証:**
   - コード → ビルド/lint/テスト
   - フロントエンド → Playwrightスクリーンショット
   - ドキュメント → frontmatter/必須セクション
   - スキル実行 → 各並列タスクの結果を個別確認
   - タスク管理 → 3層整合性
5. **差分確認** — 依頼外の変更が含まれていないか

**長時間タスク（15分超 or 3Phase超）:** 各Phase完了時に「Phase X 完了: [成果物名]」を報告し、次に進む前に確認。
