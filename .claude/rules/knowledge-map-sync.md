# ナレッジマップ同期ルール

ナレッジフォルダ（`ナレッジ/`）にファイルを追加・削除・移動した場合、作業完了後に **`ナレッジ/ナレッジマップ.canvas`** の該当カテゴリのテキストノードを更新する。

## 運用

- 各カテゴリ（ナレッジ/直下のサブフォルダ）に対応する **テキストノード** を canvas 内に1つずつ用意する
- ファイル追加 → 対応ノードにファイル名（wikilink推奨）を1行追記
- ファイル削除/移動 → 対応ノード内の該当行を削除or修正
- ノードIDは `obsidian:json-canvas` スキルで自動採番されるため、IDは気にしなくてよい

## 新カテゴリが追加された場合

既存カテゴリに当てはまらない場合は、新しいグループノードとテキストノードを追加し、中央ハブノード（vault全体の入口）からエッジを接続する。
