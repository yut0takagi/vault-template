# 外部API ホスト制限時のフォールバック

外部APIへのリクエストが「Host not in allowlist」等のネットワーク制限でブロックされた場合:

1. **エラーで処理を停止しない** — ゼロ件（0件取得）として扱い、次のタスクへ進む
2. **スキップを明示** — 「○○ API: ホスト制限のためスキップ（0件）」のように結果に記載する
3. **リトライしない** — 同じ制限に対して再試行は無意味。代替手段がなければ諦める

## 注意

外部API呼び出しが成功している環境（ローカル等）では通常通り処理すること。allowlist 設定はホスト環境（Claude Code settings等）に依存するため、対象APIのドメインを `permissions` に追加すれば解決することがある。
