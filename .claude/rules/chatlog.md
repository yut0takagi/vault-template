# チャットログ記録

毎レスポンス末尾で `ログ/チャット/sessions.jsonl`（vault相対パス）に1行追記する。後回し禁止。

```json
{
  "id": "ISO8601タイムスタンプ",
  "category": "日報|議事録|1on1準備|スライド作成|リサーチ|ナレッジ整理|コード開発|分析・データ|設定・環境構築|質問・相談|レビュー|プロジェクト管理|その他",
  "summary": "1行の概要",
  "request": "ユーザーの依頼内容",
  "duration": "短(〜5分)|普(5〜15分)|長(15分〜)",
  "skills_used": [],
  "steps": [],
  "outputs": [],
  "tags": []
}
```

- 1行1JSON、パスはvault相対、欠損は `null` or `[]`
- 忘れた場合は次の応答前に補完

## 例外

複数並列処理・長時間タスク等でファイルコンフリクトが起きやすい状況（例: 始業ルーティン）では、書き込みをスキップしてよい。ユーザーが明示的に「chatlog.md ルールは無視してよい」と指定した場合も同様。
